# RogueDuel 게임 디자인 기획서 (창작 콘텐츠)
사이버펑크 해커 듀얼 — 로그라이크 덱빌더

Document Version: 1.0
관계 문서: RogueDuel_기획서.md (기술/아키텍처 스펙)
이 문서는 위 기술 기획서의 12번(카드 효과 시스템), 13번(로그라이크 런 진행 구조) 섹션을
실제 창작 콘텐츠로 구체화한 것입니다.

역할 구분: 이 문서는 기획자(Claude) 관점에서 작성되었고, 개발자(사용자)가
그대로 구현할 수 있도록 구체적인 수치/텍스트까지 명시합니다.


==================================================
1. 세계관 한 줄 요약
==================================================

당신은 이름 없는 프리랜서 해커다.
다크넷에 접속해 기업 서버망 깊숙이 침투하며 실력을 증명하고,
그 과정에서 마주치는 다른 해커와 실시간으로 결투한다.
승부의 순간, 메인프레임은 그 누구의 편도 들지 않는다 —
오직 규칙만을 강제한다.

("메인프레임이 규칙만 강제한다"는 설정 = 실제 서버 권위 검증
아키텍처를 세계관으로 감싼 장치. 면접에서 "왜 이런 설정을 넣었나"
질문에 기술적 이유로 답할 수 있음)

2. 핵심 용어 (게임 내 명칭)
==================================================

체력          -> 시스템 무결성 (Integrity, 줄여서 INT)
자원(마나)     -> 대역폭 (Bandwidth, 줄여서 BW)
공격 카드      -> 익스플로잇 (Exploit)
방어 카드      -> 방화벽 (Firewall)
드로우 카드    -> 스캔 (Scan)
자원획득 카드  -> 오버클럭 (Overclock)
디버프(지속피해)-> 트레이스 (Trace)
리더보드       -> 다크넷 랭킹 (Darknet Ranking)
영구 재화      -> 데이터 조각 (Data Shard)
매치메이킹     -> 업링크 (Uplink)

3. 덱 아키타입 3종
==================================================

--------------------------------------------------
[침투형] INTRUSION — 초록 네온 / 후드 실루엣
--------------------------------------------------
컨셉: 빠르게 대역폭을 태워 큰 피해를 내는 공격형. 방어가 약해
      상대보다 먼저 끝내야 하는 리스크-리워드 플레이스타일.

대표 메커니즘: "체인" — 한 턴에 익스플로잇 카드를 연속 사용할수록
              다음 익스플로잇 피해가 누적 증가.


--------------------------------------------------
[방어형] FIREWALL — 청록 네온 / 회로판 패턴 실루엣
--------------------------------------------------
컨셉: 방어막을 쌓고 반격하는 지구전형. 상대의 대역폭을 고갈시키고
      역으로 되받아치는 데 특화.

대표 메커니즘: "오버실드" — 방어막이 일정 수치(15) 이상 쌓이면
              초과분이 상대에게 반사 피해로 전환.


--------------------------------------------------
[정보형] INFOTECH — 마젠타 네온 / 눈 아이콘 실루엣
--------------------------------------------------
컨셉: 카드를 순환시키고 트레이스(지속피해)를 축적시켜 터뜨리는
      콤보/엔진 빌드.

대표 메커니즘: "감염" — 상대에게 걸린 트레이스 스택 수에 비례해
              추가 피해를 주는 카드들이 존재.

[풀 인덱스] 3 | 덱 전체를 확인하고 원하는 카드 1장을 손으로 가져옴


밸런싱 메모 (개발자 참고):

- 트레이스(지속피해)는 "턴 종료 시 스택 수만큼 무결성 감소, 이후
  스택 1 감소"로 통일 (Slay the Spire의 독/Poison과 동일 룰).
- 초기 밸런스는 절대 정확할 수 없음 — 위 수치는 시작점이며,
  실제 플레이테스트 후 조정 전제. 밸런싱 자체보다 "카드 효과
  시스템이 데이터 기반으로 안전하게 동작하는가"가 더 중요한
  포트폴리오 포인트.

5. 로그라이크 노드맵 구조
==================================================

노드 타입:

SECURITY NODE (보안 노드)
  PvE 전투. 방화벽 AI, 감시봇 등 보안 프로그램과 대결.
  기술기획서 19번 섹션의 "적 5~10종"이 여기 해당.
  일반 몬스터 역할 — 로그라이크의 기본 진행 컨텐츠.

MARKET NODE (암시장 노드)
  데이터 조각/대역폭으로 카드 구매, 카드 삭제(디톡스) 가능.

DATA CACHE (데이터 캐시)
  랜덤 이벤트 노드. 리스크/리워드 선택지
  (예: "미확인 서버 진입 - 보상 또는 트레이스 부여 위험").

UPLINK NODE (업링크 노드)
  실제 매치메이킹이 발생하는 지점. 이 노드에 도달하면
  다른 플레이어와 실시간 PvP 듀얼로 연결됨.

CHECKPOINT (체크포인트)
  런의 최종 보안 시스템. 강화된 PvE 전투 (MVP는 일반 보안 노드보다
  약간 강한 버전 하나로 단순화, 다중 보스는 Stretch).


노드맵 진행 예시 (1회 런):

시작 -> SECURITY -> DATA CACHE -> MARKET -> UPLINK(PvP)
     -> SECURITY -> UPLINK(PvP) -> CHECKPOINT -> 런 종료

6. 메타 프로그레션
==================================================

런 중 임시 자원 (런 종료 시 소멸):
- 현재 덱 구성, 무결성, 대역폭

런 종료 후 영구 유지:
- 데이터 조각 (Data Shard) — PvP 승리, SECURITY 노드 클리어 시 획득
- 데이터 조각으로 다음 런 시작 시 사용할 신규 카드 언락,
  아바타 실루엣 컬러 언락 등에 사용 (MVP는 카드 언락만, 코스메틱은 Stretch)

랭킹:
- 다크넷 랭킹(리더보드) — PvP 승패 기반 레이팅(MVP는 단순 승수 집계,
  ELO는 기술기획서 9번 섹션과 동일하게 Stretch 단계에서 도입)

9. 개발자를 위한 우선순위 메모
==================================================

이 문서의 콘텐츠는 전부 "초안"입니다. 밸런싱 수치, 카드 이름,
UI 카피는 개발 중 자유롭게 수정해도 됩니다.

바뀌면 안 되는 것 (RogueDuel_기획서.md와의 연결점):

- 카드 효과는 반드시 서버가 검증한다 (11번 섹션 원칙 유지)
- 트레이스/오버실드 같은 지속 효과도 서버가 계산의 단일 진실
  공급원(source of truth)이어야 한다 — 클라이언트는 표시만 담당
- 3개 아키타입 구조는 유지하되, 카드 개별 밸런스는 유동적
